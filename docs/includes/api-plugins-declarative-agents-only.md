> [!IMPORTANT]
> MCP and API plugins provide actions within [declarative agents](../overview-declarative-agent.md). They're not standalone installable plugin packages: only the containing agent can access their functions and tools. For information about the package and action manifest relationship, see [Plugins and declarative agent actions](../plugins-overview.md#plugins-and-declarative-agent-actions).
