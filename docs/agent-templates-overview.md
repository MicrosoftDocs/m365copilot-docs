# Agent Builder templates

Agent Builder templates are prebuilt starting points for the [declarative agents](overview-declarative-agent.md) you build in Agent Builder. A template is a scaffold: it supplies a description, instructions, and suggested prompts for a specific scenario. You refine that scaffold in Agent Builder, and add your own knowledge sources and capabilities, before the agent exists.

These templates are specific to Agent Builder.

## How a template fits into building an agent

Starting from a template changes only how you begin. The rest of the work happens in Agent Builder:

1. In Microsoft 365 Copilot, in the left pane, select **New agent**.
1. Under **Start with a template**, select the template you want to use.
1. On the **Describe** tab, use natural language to refine the template, including the agent name, description, and instructions.
1. On the **Configure** tab, add an icon, knowledge sources, and capabilities.
1. Select **Create**.

The agent doesn't exist until you select **Create**. Until then, you're editing the template scaffold.

For the full build and test procedure, including how to test your agent on the **Try it** tab, see [Build agents in Agent Builder](agent-builder-build-agents.md).
